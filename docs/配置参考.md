# 配置参考（config.yaml）

公开配置 `config.yaml` 位于项目根目录（浏览器 / 日志 / 面板端口），修改后保存即生效，**无需改动代码**。私有数据（会话名、发送内容、发送时间、会话缓存、登录态、审计）**按账号隔离**在 `userdata/accounts/<别名>/` 目录（MAI-001），该目录树已被 `.gitignore` 屏蔽、整体不进 git；面板在「目标会话 / 一键触发 / 迁移」等操作时自动回写**当前账号**的 `userdata/accounts/<别名>/user_data.yaml`（定时任务条目另存 `userdata/scheduler_jobs.json`）。

## 账号目录布局（MAI-001）

每个抖音账号一个目录，四类私有数据完全独立：

| 路径 | 内容 |
| --- | --- |
| `userdata/accounts/<别名>/user_data.yaml` | 该账号的 targets / message / schedule（结构同下文字段说明） |
| `userdata/accounts/<别名>/browser_data/` | 该账号浏览器登录态（cookie） |
| `userdata/accounts/<别名>/conversations_cache.json` | 该账号会话列表缓存 |
| `userdata/accounts/<别名>/runs/` | 该账号执行记录（`<id>.json` + `<id>.log` + 截图目录） |

顶层基础设施（不分账号）：`userdata/.running`（跨进程运行守卫）、`userdata/panel_state.json`（面板记忆的上次账号）、`userdata/scheduler_jobs.json`（SCH-001 定时任务条目库）、`userdata/scheduler_state.json` / `scheduler_heartbeat.json`（守护状态与心跳）、`userdata/batch_state.json`（BAT-001 批量执行状态）、`userdata/run.log` / `panel.log`。

旧版单账号数据（顶层 `user_data.yaml` / `browser_data/` / `runs/` / `conversations_cache.json`）由面板迁移引导条或 `python main.py --migrate <别名>` 一次性迁入账号目录，迁移后顶层不再使用。

## 完整字段说明（账号私有数据 `accounts/<别名>/user_data.yaml`）

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `schedule.time` | 字符串 | `"21:30"` | 该账号每日发送时间的**默认值**。实际定时由面板「定时任务」页的任务条目（`userdata/scheduler_jobs.json`）+ 常驻守护执行；命令行 `main.py HH:MM` 路径则注册 Windows 计划任务 `DouyinAutoFire-<别名>`。**多账号请错峰 ≥15 分钟**（守护对同刻任务也会自动错峰 ≥15 分钟）。 |
| `targets` | 列表 | `[]` | 该账号的目标会话列表，可配置多个（私聊 / 群聊混合），逐个发送。**面板「一键触发 → 目标会话」卡的「保存所选」会整体覆盖此字段。** |
| `targets[].name` | 字符串 | — | 会话名称（好友昵称或群名），用于在消息列表匹配。**精确等值匹配**（会话名在列表里始终完整，无省略号、不做前缀匹配），需与抖音里显示的名称一致。 |
| `targets[].type` | 字符串 | `"private"` | `private`（私聊火花）或 `group`（群聊火花）。面板「一键触发 → 目标会话」里可逐条切换类型（扫描时已自动识别群聊作默认值）。 |
| `message.texts` | 列表 | `["在吗"]` | 发送内容，可写多条；当 `random: true` 且有多条时，每天随机抽一条更自然。 |
| `message.random` | 布尔 | `true` | 是否随机抽一条发送。面板前台触发/保存时会自动按「内容条数 > 1」设置。 |

## 完整字段说明（公开配置 `config.yaml`）

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `browser.headless` | 布尔 | `false` | 是否无头（后台）运行。`true` = 不弹浏览器窗口，但**实测抖音 100% 弹拼图验证、无法发送**，故必须保持 `false`（真实有头浏览器，窗口正常显示在屏幕内）；`false` = 弹出可见浏览器（首次登录或前台触发用）。**面板「一键触发」会强制 `false`（可见）**。 |
| `browser.user_data_dir` | 字符串 | `"./userdata/browser_data"` | **多账号下此键由账号层覆盖**（实际 = `userdata/accounts/<别名>/browser_data`），此处仅作旧版单账号兜底/示例值，多账号下无需修改。 |
| `browser.timeout` | 整数 | `60` | 元素等待超时（秒）。抖音加载慢可适当调大。 |
| `browser.strict_verify` | 布尔 | `true` | 发送成功校验强度。无条件双证据：文字进入编辑器 + 发送后输入框清空（空/纯空白内容入口拦截）。`true`=再附加最后气泡文本比对（推荐）；`false`=跳过气泡比对（气泡锚点失配时的应急退化）。 |
| `browser.extra_args` | 列表 | `["--disable-blink-features=AutomationControlled","--no-sandbox"]` | 额外浏览器启动参数。一般无需改动。 |
| `browser.channel` | 字符串 | `"chrome"` | 使用本机已安装的 Chrome/Edge 而非 Playwright 自带 Chromium。`"chrome"` 用 Chrome，`"msedge"` 用 Edge，留空用自带 Chromium。**用真实浏览器指纹更正常，更不易被识别。** 需本机已安装对应浏览器。 |
| `browser.real_chrome_profile` | 布尔 | `false` | 进阶：复用你本机真实 Chrome 的登录态目录。⚠️ **多账号下必须保持 `false`**：为 `true` 时登录态会指向真实 Chrome 目录、绕过账号隔离，两个账号共用同一份登录态（串号）。开启前还必须**关闭正在用的 Chrome**（否则目录被占用启动失败）。 |
| `logging.file` | 字符串 | `"./userdata/run.log"` | 运行日志文件路径（全局基础设施日志），留空则只打印到控制台。 |
| `panel.port` | 整数 | `8765` | 管理面板监听端口。修改后重启面板生效。 |

## 示例配置

`config.yaml`（公开）：

```yaml
# 抖音自动续火花 - 配置文件
# 修改后保存即可生效，无需改代码。

browser:
  # 是否无头（后台）运行。
  # ⚠️ 实测：headless: true 时抖音 100% 弹出拼图滑块验证，任务会立刻停手无法发送。
  #    因此必须保持 headless: false（真实有头浏览器），窗口正常显示在屏幕内。
  headless: false
  # 浏览器数据目录：多账号下此键由账号层覆盖（实际 = userdata/accounts/<别名>/browser_data）。
  # 此处仅作旧版单账号兜底/示例值，多账号下无需修改。
  user_data_dir: "./userdata/browser_data"
  # 元素等待超时（秒）
  timeout: 60
  # 发送成功校验强度：true=文字落地+输入框清空+气泡文本比对（推荐）；
  # false=跳过气泡比对（文字落地+清空仍强制；空内容入口拦截）
  strict_verify: true
  # 额外反自动化启动参数（一般无需改动）
  extra_args:
    - "--disable-blink-features=AutomationControlled"
    - "--no-sandbox"
  # 可选：使用本机已安装的 Chrome/Edge 而非 Playwright 自带的 Chromium，
  # 指纹更“正常”，更不容易被识别为自动化。需本机已安装对应浏览器。
  # 留空用自带 chromium；本机装了 Chrome 可填 "chrome"，装了 Edge 填 "msedge"。
  channel: "chrome"
  # ⚠️ 多账号目录隔离（MAI-001）：real_chrome_profile 必须保持 false。
  #    为 true 时登录态会指向真实 Chrome 目录、绕过账号隔离，两个账号会共用同一份登录态（串号）。
  real_chrome_profile: false

logging:
  # 运行日志文件，留空则只打印到控制台
  file: "./userdata/run.log"

panel:
  # 管理面板（python panel.py）监听的端口，默认 8765
  port: 8765
```

`userdata/accounts/<别名>/user_data.yaml`（账号私有，面板添加账号/迁移时自动生成）：

```yaml
targets:
  - name: "示例学习群"
    type: group
  - name: "示例用户A"
    type: private

message:
  # 发送内容，可写多条，开启 random 后每天随机抽一条，更自然
  texts:
    - "示例内容一"
    - "早安，今天的火花来啦"
  random: true

schedule:
  time: "21:30"            # 每天发送时间，24 小时制，例如 "08:00" / "23:00"
```

## 面板如何回写配置

面板在以下操作时会修改**当前账号**的 `userdata/accounts/<别名>/user_data.yaml`（私有数据文件，不进 git）：

- **「一键触发」→ 目标会话卡「保存所选」**：整体覆盖该账号的 `targets`（含 `name` 与 `type`）。
- **「一键触发」→ 前台触发 / 保存内容**：把发送内容写入该账号的 `message.texts`，并按条数设置 `message.random`。
- **账户迁移 / 添加账号**：生成该账号的 `user_data.yaml` 骨架（`schedule.time` 默认 `21:30`）并按需迁入旧数据。

定时任务则是**另一套数据**：面板「定时任务」页新建/修改的是任务条目（`userdata/scheduler_jobs.json`，账号 / 时刻 / 目标 / 文案为任务独立副本），由常驻守护执行，**不写回**账号的 `message`；「一键迁移」把旧版 `schedule.time` 转成条目，「清理旧系统任务」删除旧 `DouyinAutoFire-<别名>` 计划任务。

> 第一次使用建议先在面板「一键触发 → 目标会话」里勾选并保存，避免手写 `targets` 时昵称拼写不符导致匹配失败。

## 关于 `channel` 与 `real_chrome_profile`

- **`channel: "chrome"`**（推荐）：使用本机 Chrome 启动浏览器，指纹比 Playwright 自带 Chromium 更像真人，能显著降低被风控的概率。前提是本机已安装 Chrome。
- **`real_chrome_profile: true`**（⚠️ 多账号下禁用）：直接复用你日常使用的 Chrome 登录态（cookie、设备信任）。**多账号期间必须保持 `false`**——该键为 `true` 时会绕过账号 `browser_data` 隔离，两个账号共用同一份 Chrome 登录态，正是串号场景。单账号时代它也要求**退出你正在用的 Chrome** 才能启动。
- 单账号且不开多账号功能时才考虑 `channel: "chrome"` + `real_chrome_profile: true` 叠加；本项目现状（多账号）不适用。
