# 配置参考（config.yaml）

公开配置 `config.yaml` 位于项目根目录（浏览器 / 日志 / 面板端口），修改后保存即生效，**无需改动代码**。私有数据（会话名、发送内容、发送时间、会话缓存、登录态、审计）统一在 `userdata/` 目录（`userdata/user_data.yaml` 等），该目录已被 `.gitignore` 屏蔽、整体不进 git，缺失时程序自动新建骨架；面板在「选会话 / 定时任务 / 保存内容」等操作时也会自动回写 `userdata/user_data.yaml`。

---

## 完整字段说明

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `schedule.time` | 字符串 | `"21:30"` | 每日发送时间，24 小时制 `HH:MM`。若用 Windows 任务计划程序（推荐），此时间仅作 `--run-once` 参考；真正定时由任务计划程序控制。若用程序内置常驻循环，则按此时间运行。 |
| `targets` | 列表 | `[]` | 目标会话列表，可配置多个（私聊 / 群聊混合），逐个发送。**面板「选会话」的「保存所选」会整体覆盖此字段。** |
| `targets[].name` | 字符串 | — | 会话名称（好友昵称或群名），用于在消息列表匹配。需与抖音里显示的昵称/群名一致（截断名也可匹配前缀）。 |
| `targets[].type` | 字符串 | `"private"` | `private`（私聊火花）或 `group`（群聊火花）。面板「选会话」里可逐条切换类型。 |
| `message.texts` | 列表 | `["在吗"]` | 发送内容，可写多条；当 `random: true` 且有多条时，每天随机抽一条更自然。 |
| `message.random` | 布尔 | `true` | 是否随机抽一条发送。面板前台触发/保存时会自动按「内容条数 > 1」设置。 |
| `browser.headless` | 布尔 | `false` | 是否无头（后台）运行。`true` = 不弹浏览器窗口，但**实测抖音 100% 弹拼图验证、无法发送**，故必须保持 `false`（真实有头浏览器，窗口正常显示在屏幕内）；`false` = 弹出可见浏览器（首次登录或前台触发用）。**面板「一键触发」会强制 `false`（可见）**。 |
| `browser.user_data_dir` | 字符串 | `"./userdata/browser_data"` | 浏览器数据目录，登录态（cookie）持久化到这里（位于 `userdata/` 内，整体 gitignore），**请勿删除**。 |
| `browser.timeout` | 整数 | `60` | 元素等待超时（秒）。抖音加载慢可适当调大。 |
| `browser.strict_verify` | 布尔 | `true` | 发送成功校验强度。`true`=输入框清空 + 最后一条气泡回读双重校验（推荐）；`false`=仅校验输入框清空，气泡不符只告警并留审计证据。仅在气泡锚点因抖音改版失配、导致真实发送被误判为失败时才降级。 |
| `browser.extra_args` | 列表 | `["--disable-blink-features=AutomationControlled","--no-sandbox"]` | 额外浏览器启动参数。一般无需改动。 |
| `browser.channel` | 字符串 | `"chrome"` | 使用本机已安装的 Chrome/Edge 而非 Playwright 自带 Chromium。`"chrome"` 用 Chrome，`"msedge"` 用 Edge，留空用自带 Chromium。**用真实浏览器指纹更正常，更不易被识别。** 需本机已安装对应浏览器。 |
| `browser.real_chrome_profile` | 布尔 | `false` | 进阶：复用你本机真实 Chrome 的登录态目录（指纹正常 + 设备已信任 + 已登录 → 打开不弹验证）。开启前**必须关闭正在用的 Chrome**（否则目录被占用启动失败）。默认关闭，靠 `channel: chrome` 已足够。 |
| `logging.file` | 字符串 | `"./run.log"` | 运行日志文件路径，留空则只打印到控制台。 |
| `panel.port` | 整数 | `8765` | 管理面板监听端口。修改后重启面板生效。 |

## 示例配置

```yaml
# 抖音自动续火花 - 配置文件
# 修改后保存即可生效，无需改代码。

schedule:
  time: "21:30"            # 每天发送时间，24 小时制，例如 "08:00" / "23:00"

targets:
  - name: "示例学习群"
    type: group
  - name: "示例用户A"
    type: private

message:
  # 发送内容，可写多条，开启 random 后每天随机抽一条，更自然
  texts:
    - "示例内容一"
    - "早安，今天的火花来啦"
  random: true

browser:
  # 是否无头（后台）运行。
  # ⚠️ 实测：headless: true 时抖音 100% 弹出拼图滑块验证，任务会立刻停手无法发送。
  #    因此必须保持 headless: false（真实有头浏览器），窗口正常显示在屏幕内。
  headless: false
  # 浏览器数据目录：登录态（cookie）会持久化到这里（位于 userdata/ 内，整体 gitignore），请勿删除
  user_data_dir: "./userdata/browser_data"
  # 元素等待超时（秒）
  timeout: 60
  # 发送成功校验强度：true=输入框清空+气泡回读双重校验（推荐）；
  # false=仅校验输入框清空（气泡锚点失配时的应急退化）
  strict_verify: true
  # 额外反自动化启动参数（一般无需改动）
  extra_args:
    - "--disable-blink-features=AutomationControlled"
    - "--no-sandbox"
  # 可选：使用本机已安装的 Chrome/Edge 而非 Playwright 自带的 Chromium，
  # 指纹更“正常”，更不容易被识别为自动化。需本机已安装对应浏览器。
  # 留空用自带 chromium；本机装了 Chrome 可填 "chrome"，装了 Edge 填 "msedge"。
  channel: "chrome"
  # 进阶：复用你本机“真实 Chrome”的登录态目录（指纹正常 + 设备已信任 + 已登录 → 程序打开也不弹验证）。
  # 开启前请先关闭你正在用的 Chrome 浏览器（否则目录被占用会启动失败）。设为 true 后 user_data_dir 自动指向真实 Chrome 目录。
  # 默认关闭：用户要求不使用本机 Chrome 登录态，改回项目自带 userdata/browser_data（channel=chrome 已足够）。
  real_chrome_profile: false

logging:
  # 运行日志文件，留空则只打印到控制台
  file: "./run.log"

panel:
  # 管理面板（python panel.py）监听的端口，默认 8765
  port: 8765
```

## 面板如何回写配置

面板在以下操作时会修改 `user_data.yaml`（私有数据文件，不进 git）：

- **「选会话」→ 保存所选**：整体覆盖 `targets`（含 `name` 与 `type`）。
- **「一键触发」→ 前台触发 / 保存内容**：把发送内容写入 `message.texts`，并按条数设置 `message.random`。
- **「定时任务」→ 保存并注册定时任务**：写入 `schedule.time` 与 `message.texts`，并注册系统定时任务。

> 第一次使用建议先在面板「选会话」里勾选并保存，避免手写 `targets` 时昵称拼写不符导致匹配失败。

## 关于 `channel` 与 `real_chrome_profile`

- **`channel: "chrome"`**（推荐）：使用本机 Chrome 启动浏览器，指纹比 Playwright 自带 Chromium 更像真人，能显著降低被风控的概率。前提是本机已安装 Chrome。
- **`real_chrome_profile: true`**（谨慎）：直接复用你日常使用的 Chrome 登录态（cookie、设备信任）。优点是完全免去扫码；缺点是必须**退出你正在用的 Chrome** 才能启动，否则用户数据目录被占用会启动失败。默认 `false`。
- 两者可以叠加：`channel: "chrome"` + `real_chrome_profile: true` 时，会强制走真实 Chrome 目录。
