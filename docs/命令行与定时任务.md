# 命令行与定时任务

除了管理面板，本项目也可以用命令行直接操作。`main.py` 是入口，`panel.py` 是面板服务。定时任务由 **Windows 任务计划程序**承载。

---

## 一、`main.py` 用法

### 交互模式（直接运行）

```bash
python main.py
```

```
==========================================
       抖音自动续火花
  [1] 手动触发   = 立即给所有目标发一次
  [2] 定时触发   = 设为每天定时自动发
==========================================
请选择 (1=手动 / 2=定时)：
```

- 选择后输入要发送的内容（每行一条，可多条用于随机轮换，空行结束）。
- **手动触发（选 1）**：用本次输入内容**立即**给 `config.yaml` 的 `targets` 各发一次，**不改动配置文件**。
- **定时触发（选 2）**：再输入时间（如 `21:30`），把时间与内容写回 `config.yaml`，并注册 Windows 定时任务；之后每天到点自动发。

### 非交互用法

```bash
python main.py --run-once      # 立即发送一次（使用 config.yaml 的内容）
python main.py 21:30           # 非交互：直接设为每日 21:30 定时（使用 config.yaml 的内容）
python main.py --setup-login   # 仅打开浏览器登录/解验证码（不发送）
python main.py --test          # 仅验证依赖与浏览器能否启动（不登录、不发送）
```

参数说明：

| 参数 | 含义 |
| --- | --- |
| 位置参数 `HH:MM` | 直接设为每日定时（非交互） |
| `--run-once` | 立即发送一次后退出（供任务计划程序调用） |
| `--setup-login` | 仅打开浏览器供手动登录 / 解验证码，不发送 |
| `--test` | 仅测试依赖与浏览器启动 |

> 定时任务注册成功后，每天到点执行的实际命令就是 `python main.py --run-once`（见下文）。

## 二、Windows 定时任务（核心机制）

### 注册方式

**方式 A：通过面板（推荐）**
「定时任务」页填时间 + 内容 → 点「保存并注册定时任务」。后端用 `schtasks` 命令行创建任务。

**方式 B：通过 `main.py`**
交互选 2 或 `python main.py 21:30` → 内部调用注册逻辑（与面板共用同一套 `schtasks` 命令）。

**方式 C：手动（可选）**

已删除 `setup_windows_task.ps1`：它用 `Register-ScheduledTask`（COM），
在面板的后台子进程（MTA 公寓模式）里会失败。面板与 `main.py` 统一使用 `schtasks` 命令行。

### 任务画像

- **任务名**：`DouyinAutoFire`（固定，不可改）。
- **级别**：**普通用户级任务**（登录时运行即可），**不需要管理员权限**。
  - ⚠️ 不要加 `/RL HIGHEST`（最高权限），普通用户会「拒绝访问」。
- **触发器**：每天 `ST` 指定的时间（`/SC DAILY`）。
- **操作（Action）**：`"<pythonw.exe>" "<项目>\runner.py" --run-once`
  - 用 **`pythonw.exe`** 而非 `cmd /c python`：到点不会弹出控制台黑框。
  - `runner.py` 自己 `chdir` 到项目根，并把任何早期异常（依赖缺失等）写进 `run.log`，
    杜绝「任务 exit 1 但日志一片空白」的黑盒。
  - 解释器路径由 `pyenv.py` **每次注册时重新探测并校验**（必须能 `import playwright`），
    不再硬编码——避免 venv 被删/迁移后任务静默失效。
- **运行状态**：成功注册后默认「已启用」。

### ⚠️ headless 与抖音风控（重要）

实测：`browser.headless: true` 时抖音**必定**弹出拼图滑块验证，任务立刻停手，一条也发不出去。

所以定时任务必须用 **真实有头浏览器**（`config.yaml`）：

```yaml
browser:
  headless: false     # 真实有头浏览器，指纹正常，不触发风控，窗口正常显示在屏幕内
```

> 定时任务运行时浏览器窗口是可见的（会弹出一个 Chrome 窗口）。若希望它不抢焦点，请勿最小化/移动窗口——保持 `headless: false` 即可，抖音对无头浏览器风控最严。

### 健康自检

面板「定时任务」页的 `/api/tasks` 会返回 `health` 字段，自动检查三类历史故障：

1. 定时任务指向的 `python.exe` 已不存在（venv 被删/迁移）；
2. 本机找不到可用的 `.venv`；
3. `headless: true`（会被风控拦截）。

### 启用 / 禁用 / 删除

通过面板「定时任务」页的三个按钮操作（未注册时按钮置灰）：

- 启用：重新启用被禁用的任务。
- 禁用：暂停任务（不再到点运行，但保留任务定义）。
- 删除：从系统移除 `DouyinAutoFire` 任务。

等价于命令行：
```bash
schtasks /Change /TN DouyinAutoFire /Enable
schtasks /Change /TN DouyinAutoFire /Disable
schtasks /Delete /TN DouyinAutoFire /F
```

### 查看状态

```bash
schtasks /Query /TN DouyinAutoFire /FO LIST /V
```

## 三、项目内置脚本（.bat / .vbs）

| 文件 | 用途 |
| --- | --- |
| `启动面板.vbs` | 双击启动管理面板（无窗口），自动打开浏览器到 `http://127.0.0.1:8765`。推荐日常用。 |
| `启动面板.bat` | 同上，通过 `pythonw` 无窗口启动。 |
| `停止面板.bat` | 双击停止后台面板服务（按命令行匹配 `panel.py` 进程强杀）。 |
| `抖音续火花.bat` | 双击运行：命令行菜单模式（`python main.py`），弹出窗口选 1/2 并输入内容，结束后按任意键关闭。 |

> 这些脚本会自动定位虚拟环境 Python：优先
> `%USERPROFILE%\.workbuddy\binaries\python\envs\douyin-auto-fire\Scripts\pythonw.exe`（或 `python.exe`），找不到再回退。
>
> 如果你的环境不是这个路径，请直接用 `python panel.py` / `python main.py`（需先 `pip install -r requirements.txt` + `playwright install chromium`）。

---

## 四、启动方式备注（pythonw vs python）

- `启动面板.bat` / `启动面板.vbs` 使用 `pythonw.exe`（无控制台窗口）。
- 在部分后台托管/沙箱环境下 `pythonw` 可能异常退出（exit 码异常）。若发现面板起不来，**改用 `python.exe panel.py` 前台启动**最稳妥（多占用一个终端窗口）。
- 无论哪种方式，面板监听端口由 `config.yaml` 的 `panel.port` 决定（默认 8765），重复启动会先清理旧实例占用的端口。

## 五、纯程序内置循环（兜底）

若系统任务计划程序注册始终失败（如被组策略禁用 `schtasks`），`main.py` 还提供一个兜底：**程序常驻循环**（`schedule` 库），保持窗口打开，每天到点自动发送。

```bash
python main.py 21:30    # 若注册失败，会自动退化为常驻循环
```

> 常驻循环需要窗口一直开着，不如系统任务计划程序「关窗口也能跑」方便，建议优先解决 `schtasks` 注册问题。
