# 管理面板使用指南

管理面板是一个本地 Web 服务（`python panel.py`），默认地址 **http://127.0.0.1:8765**。纯本地运行，**不联网、不上传任何数据**。

---

## 一、启动面板

推荐用项目内置脚本（已配置好虚拟环境路径）：

- **双击 `启动面板.vbs`**（完全无窗口，推荐日常使用）：后台启动服务并自动打开浏览器到面板页。
- **双击 `启动面板.bat`**：同样无窗口，用 `pythonw` 后台启动。
- **命令行**：`python panel.py`，会在终端看到日志，浏览器访问 `http://127.0.0.1:8765`。

> ⚠️ **必须用以上方式打开面板，不要直接双击 `panel.html`。** 直接双击 HTML 文件时浏览器用的是 `file://` 协议，连不上本地服务，会导致「定时任务」「执行记录」一直显示“加载失败”，“一键触发”因是纯表单看似正常但无法真正运行。
>
> 若你已不慎用 `file://` 打开了页面，面板会显示一个明显的「打开方式不对」提示，按提示点击「打开面板 http://127.0.0.1:8765」即可。

**关闭面板**：页面右上角「退出面板」按钮（会停止后台服务，已注册的 Windows 定时任务不受影响）；或双击 `停止面板.bat`。

> 启动方式备注：在 WorkBuddy 等某些后台托管环境下，`pythonw`（无窗口）可能异常退出，此时请用 `python.exe panel.py` 前台启动（会占用一个终端窗口，但最稳定）。面板进程异常退出后，再次双击启动脚本即可（脚本会先清理已占用的端口）。

## 二、顶部状态条与按钮

- **状态药丸**（右上角）：显示「就绪」或「运行中：<运行ID>」；若「打开浏览器」窗口仍开着，会显示「浏览器窗口打开中…」。
- **重置运行**（红色，仅在显示「运行中」时出现）：当后端任务实际已结束但面板仍卡在「运行中」时的兜底按钮，点一下释放触发锁。
- **强制重置**（红色，仅在「浏览器窗口打开中」超过 8 秒后出现）：当浏览器已关闭但面板仍卡在「打开中」时的兜底按钮。
- **退出面板**（右上角）：停止后台服务。

---

## 三、标签页①「一键触发」

立即给「选会话」里已保存的目标各发一次消息。**会弹出可见浏览器实时运行**，你能看着它点消息、开会话、打字；遇到安全验证时直接在弹出的浏览器里手动处理。

- **发送内容** 文本框：每行一条，多条则每次随机抽一条（开启 `random`）。
- **前台触发**：用框内内容立即发送一次。发送内容会自动保存到 `config.yaml`，下次进面板自动带出。
- **保存内容**：仅把内容写回配置，不发送。
- **打开浏览器**：临时弹出可见浏览器，供手动登录或处理安全验证；关闭窗口后回到「一键触发」重新点「前台触发」即可。
- 触发后下方会出现一个**实时步骤条**，显示形如「本次共 2 条 · 已发 1 条 · 正在给 用户xxx 发送：正在打开会话…」的进度；原始完整日志在「执行记录」里查看。
- 运行中「前台触发 / 保存内容 / 打开浏览器」会**自动置灰**，避免并发。

---

## 四、标签页②「选会话」

免手写配置：自动同步你的抖音私信 / 群聊列表。

- **一键同步**：弹出可见浏览器，扫描你的消息列表（约 1~2 分钟），扫描完成后列出所有会话。扫描时「一键同步」按钮会禁用并显示「扫描中…」。
- **全选 / 反选**：快速勾选。
- **类型列**：每条会话可选择「私聊」或「群聊」。火花类型务必选对（私聊火花 vs 群聊火花）。
- **保存所选**：把勾选的会话（含类型）整体写入 `config.yaml` 的 `targets`；已保存的会话会显示在最上方并默认勾选，面板重启后也会保留（写入 `conversations_cache.json`）。
- 只有「保存所选」之后的会话，才会出现在「一键触发 / 定时任务」的实际发送目标里。

## 五、标签页③「定时任务」

### 系统定时任务（顶部卡片）

显示当前 Windows 任务计划程序里 `DouyinAutoFire` 任务的状态：

- 若已注册：`DouyinAutoFire · 状态：已启用/已禁用 · 下次运行：… · 上次结果：…`。
- 若未注册：`DouyinAutoFire：尚未注册系统定时任务。请先在下方设置每天发送时间与内容，再点击「保存并注册定时任务」。`

**启用 / 禁用 / 删除** 三个按钮：

- 仅对**已注册**的任务生效。未注册时这三个按钮会**自动置灰禁用**。
- 启用：把已注册但禁用的任务重新启用；禁用：暂停任务；删除：从系统移除该任务。

### 设置每日定时（下方卡片）

- **每天发送时间**（HH:MM，24 小时制）。
- **发送内容**（每行一条，多条随机）。
- **保存并注册定时任务**：把时间与内容写入 `config.yaml`，并用 `schtasks` 注册普通用户级 Windows 每日任务（**无需管理员权限**）。成功后顶部卡片会立即显示「已启用」。

> 若保存接口返回错误（如「系统定时任务被拒绝访问」），通常是被安全软件/组策略拦截，可尝试「以管理员身份」启动面板后再注册，或见 [docs/故障排查.md](故障排查.md)。

## 六、标签页④「执行记录」

每一次运行（手动触发或定时触发）都会留下一条记录，**只保留最近 3 条**，更早的连同截图目录会被自动彻底删除。

- **列表**：时间、状态、目标。
  - 状态徽章：`运行中` / `成功` / `需验证` / `失败`。
- **点击任意一行**打开「执行详情」弹窗：
  - **元信息**：开始/结束时间、状态、目标、错误（若有）。
  - **需验证提示**：若状态为「需验证」，会给出明确指引（去「一键触发」点「打开浏览器」手动处理，再重新触发）。
  - **完整日志**：本次运行的全部日志文本。
  - **证据截图**：本次运行在关键节点保存的截图（打开会话、发送后、失败审计），点击可放大查看（灯箱）。
    - 截图文件名形如 `001_175445_audit_no_match.png` 或 `005_175500_after_send.png`，前缀序号即执行顺序。

## 七、并发与清理规则

- **同一时刻只能有一个任务在跑**（浏览器数据目录锁冲突）。触发运行时其他触发类按钮会禁用；若状态卡死用「重置运行」兜底。
- **「打开浏览器」窗口**与「选会话同步」「触发运行」互斥（共用 `user_data_dir`），会相互等待。
- 执行记录**只保留最近 3 条**；删除是连同元数据、日志、截图目录一并彻底删除，不残留。
- 面板每次启动也会先裁剪一次旧记录。

## 八、接口一览（供进阶/二次开发）

面板为纯标准库 `http.server`，无外部依赖，主要路由：

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/state` | 当前运行状态、进度、配置摘要 |
| GET | `/api/runs` | 执行记录列表（自动裁剪到最近 3 条） |
| GET | `/api/runs/<id>` | 单次运行详情（元数据 + 日志 + 进度） |
| GET | `/api/runs/<id>/screenshots` | 该次运行的证据截图列表 |
| GET | `/api/screenshots/<id>/<file>` | 单张截图文件（含路径穿越防护） |
| GET | `/api/tasks` | 系统定时任务状态、当前时间/内容 |
| GET | `/api/conversations` | 会话同步状态、已扫描列表、已保存目标 |
| POST | `/api/trigger` | 触发一次运行（强制可见浏览器） |
| POST | `/api/save-message` | 仅保存发送内容 |
| POST | `/api/setup-login` | 打开可见浏览器供登录/验证 |
| POST | `/api/login-reset` | 强制重置登录窗口状态 |
| POST | `/api/run-reset` | 强制重置运行状态 |
| POST | `/api/sync-conversations` | 启动会话扫描 |
| POST | `/api/save-targets` | 保存所选会话 |
| POST | `/api/tasks` | 保存时间/内容并注册定时任务 |
| POST | `/api/tasks/enable` `/disable` `/delete` | 启用/禁用/删除系统任务 |
| POST | `/api/shutdown` | 退出面板服务 |
