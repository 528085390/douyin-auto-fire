# 管理面板使用指南

管理面板是一个本地 Web 服务（`python panel.py`），默认地址 **http://127.0.0.1:8765**。纯本地运行，**不联网、不上传任何数据**。

---

## 一、启动面板

推荐用项目内置脚本（已配置好虚拟环境路径）：

- **双击 `启动面板.vbs`**（完全无窗口，推荐日常使用）：后台启动服务并自动打开浏览器到面板页。
- **双击 `启动面板.bat`**：同样无窗口，用 `pythonw` 后台启动。
- **命令行**：`python panel.py`，会在终端看到日志，浏览器访问 `http://127.0.0.1:8765`。

> ⚠️ **必须用以上方式打开面板，不要直接双击 `panel.html`。** 直接双击 HTML 文件时浏览器用的是 `file://` 协议，连不上本地服务，会导致「定时任务」「执行记录」一直显示“加载失败”，“一键触发”因是纯表单看似正常但无法真正运行。
>
> 若你已不慎用 `file://` 打开了页面，面板会显示一个明显的「打开方式不对」提示，按提示点击「打开面板 http://127.0.0.1:8765」即可。

**关闭面板**：页面右上角「退出面板」按钮（会停止后台服务，已注册的 Windows 定时任务不受影响）；或双击 `停止面板.bat`。

> 启动方式备注：在 WorkBuddy 等某些后台托管环境下，`pythonw`（无窗口）可能异常退出，此时请用 `python.exe panel.py` 前台启动（会占用一个终端窗口，但最稳定）。面板进程异常退出后，再次双击启动脚本即可（脚本会先清理已占用的端口）。

## 一B、账号栏（MAI-001 多账号）

标题下、页签上是**账号栏**，管理多个抖音号（每号一个独立目录与登录态）：

- **当前账号下拉**：切换当前操作的账号；切换后「一键触发 / 定时任务 / 执行记录」三块数据全部随账号联动（会话勾选、发送内容、执行记录、定时任务都只反映当前账号）。只有一个账号且无待迁移旧数据时下拉自动隐藏。
- **运行中徽标**：任一账号在运行（含另一账号的定时任务撞车）时显示「运行中: <别名>」；此时本账号的触发 / 登录 / 同步 / 保存按钮全部置灰，提示「账号 <X> 正在运行中」——跨进程 `.running` 守卫保证同一时刻绝不并发。
- **＋ 添加账号**：弹输入框，别名限 1~24 个英文/数字/下划线（不能用中文、空格、`-`、Windows 保留设备名如 `CON`）；创建成功后自动切换到新账号并弹出浏览器引导扫码登录。
- **迁移引导条**（黄色，仅检测到旧版单账号数据时显示）：输入别名点「开始迁移」，把旧的 `user_data.yaml / browser_data / runs / conversations_cache.json` 整体迁入 `accounts/<别名>/`（幂等可重跑）；迁移后若检测到旧任务 `DouyinAutoFire` 仍存在，会亮出「**同步注册新任务并删除旧任务**」按钮——用该账号已保存的时间/内容注册 `DouyinAutoFire-<别名>` 并删除旧任务。
  - ⚠️ 若旧数据里只有 `browser_data/runs`（没设过发送时间），迁移补的骨架默认是 `21:30` /「在吗」——直接点收尾按钮会按默认值注册。请先到「定时任务」页核对/改成你的真实时间与内容再注册。
- **空态**：一个账号都没有时，整页显示「添加第一个账号」引导。
- 面板记住上次选择的账号（`userdata/panel_state.json`），重启后自动回到该账号。

> 删除账号 = 手动删 `userdata/accounts/<别名>/` 目录 + 删除对应定时任务（面板不提供删除账号 UI）。
> 多账号定时请**错峰 ≥15 分钟**（如 21:00 / 21:30），避免撞车时后一个号被守卫跳过。

## 一C、「一键出发」：全部账号串行批量执行（BAT-001）

账号栏右侧的 **🚀 一键出发** 把**全部已添加账号**顺次跑完各自的私聊任务
（各号用**自己已保存的文案与目标会话**），一次点击替代逐号手动切号触发：

- **串行 + 强制错峰**：同一时刻仍只跑一个号（沿用跨进程 `.running` 守卫，绝不并发）；
  号间**结束→启动强制间隔 15 分钟**（上一号实际跑完后才开始计时），整批时长 ≈
  各号运行时长之和 + 15×(号数−1) 分钟。
- **独立执行器进程**：点击后面板以 `pythonw` 拉起独立进程 `batch_runner.py`
  （类似定时任务 runner），**面板可以关闭**，批量继续执行不受影响；重开面板横幅自动恢复。
- **进度横幅**（账号栏下方，任意页签可见）：逐号状态徽章——
  `排队中 / 等待当前任务结束 / 错峰等待(距启动倒计时) / 运行中 / 成功 / 部分失败 /
  失败 / 需验证 / 已跳过`；头部显示进度 i/N 与取消按钮。
- **取消**：点「取消（当前号跑完后停止）」——错峰/等待期间立即停；正在跑的号会
  自然跑完再停，**不会中途杀浏览器**。
- **防双发**：某号在本批开始后已被执行过（如定时任务恰巧到点抢先）→ 该号自动跳过
  并在横幅写明原因，避免同号一天两轮的无意重复。
- **已跳过原因**：横幅写明（未保存内容 / 未配置目标会话 / 尚未登录 / 本批开始后
  已执行过 / 用户取消），逐一处理后可单号补跑或整批重按。
- 批量进行中，单号「前台触发 / 打开浏览器 / 一键同步 / 保存」按钮置灰（后端同样拒绝，
  双保险）；「执行记录 / 定时任务」页签仍可自由查看。
- ⚠️ 注意：批量内每号按**该号 config 的 headless 设置**运行（与定时任务一致；
  与手动触发的强制可见不同）。某号若因安全验证停在「需验证」，横幅终态会提示，
  处理方式同单号（「打开浏览器」→ 手动验证 → 重触发）。
- ⚠️ 若横幅显示「批量执行器已中断」：重按一键出发会令**已完成账号再发一轮**
  （与手动触发两轮等价），或对剩余账号单号补跑。

## 二、顶部状态条与按钮

- **状态药丸**（右上角）：显示「就绪」或「运行中：<运行ID>」；若「打开浏览器」窗口仍开着，会显示「浏览器窗口打开中…」。
- **重置运行**（红色，仅在显示「运行中」时出现）：当后端任务实际已结束但面板仍卡在「运行中」时的兜底按钮，点一下释放触发锁。
- **强制重置**（红色，仅在「浏览器窗口打开中」超过 8 秒后出现）：当浏览器已关闭但面板仍卡在「打开中」时的兜底按钮。
- **退出面板**（右上角）：停止后台服务。

## 三、标签页①「一键触发」

立即给当前账号「选会话」里已保存的目标各发一次消息。**会弹出可见浏览器实时运行**，你能看着它点消息、开会话、打字；遇到安全验证时直接在弹出的浏览器里手动处理。

- **发送内容** 文本框：每行一条，多条则每次随机抽一条（开启 `random`）。
- **前台触发**：用框内内容立即发送一次（当前账号）。发送内容会自动保存到该账号的私有配置，下次进面板自动带出。
- **保存内容**：仅把内容写回当前账号配置，不发送。
- **打开浏览器**：临时弹出可见浏览器，供当前账号手动登录或处理安全验证；关闭窗口后回到「一键触发」重新点「前台触发」即可。
- 触发后下方会出现一个**实时步骤条**，显示形如「本次共 2 条 · 已发 1 条 · 正在给 用户xxx 发送：正在打开会话…」的进度；原始完整日志在「执行记录」里查看。
- 运行中（含**另一账号**在运行）「前台触发 / 保存内容 / 打开浏览器」会**自动置灰**，避免并发。

## 四、标签页②「选会话」

免手写配置：自动同步**当前账号**的抖音私信 / 群聊列表。

- **一键同步**：弹出可见浏览器，扫描当前账号的消息列表（约 1~2 分钟），扫描完成后列出所有会话。扫描时「一键同步」按钮会禁用并显示「扫描中…」。
- **全选 / 反选**：快速勾选。
- **类型列**：每条会话可选择「私聊」或「群聊」。火花类型务必选对（私聊火花 vs 群聊火花）。
- **保存所选**：把勾选的会话（含类型）整体写入**当前账号**的 `user_data.yaml` 的 `targets`；已保存的会话会显示在最上方并默认勾选，面板重启后也会保留（写入该账号的 `conversations_cache.json`）。切换账号后列表立即换成新账号的缓存，不会串号。
- 只有「保存所选」之后的会话，才会出现在「一键触发 / 定时任务」的实际发送目标里。

## 五、标签页③「定时任务」

### 系统定时任务（顶部卡片）

显示当前 Windows 任务计划程序里**当前账号**的 `DouyinAutoFire-<别名>` 任务的状态：

- 若已注册：`DouyinAutoFire-main · 状态：已启用/已禁用 · 下次运行：… · 上次结果：…`。
- 若未注册：`DouyinAutoFire-<别名>：尚未注册系统定时任务。请先在下方设置每天发送时间与内容，再点击「保存并注册定时任务」。`

**启用 / 禁用 / 删除** 三个按钮：

- 仅对**当前账号已注册**的任务生效。未注册时这三个按钮会**自动置灰禁用**。
- 启用：把已注册但禁用的任务重新启用；禁用：暂停任务；删除：从系统移除该账号的任务。

### 设置每日定时（下方卡片）

- **每天发送时间**（HH:MM，24 小时制）。多账号请**错峰 ≥15 分钟**（如 21:00 / 21:30）。
- **发送内容**（每行一条，多条随机）。
- **保存并注册定时任务**：把时间与内容写入**当前账号**的 `user_data.yaml`，并用 `schtasks` 注册普通用户级 Windows 每日任务 `DouyinAutoFire-<别名>`（**无需管理员权限**）。成功后顶部卡片会立即显示「已启用」。

> 若保存接口返回错误（如「系统定时任务被拒绝访问」），通常是被安全软件/组策略拦截，可尝试「以管理员身份」启动面板后再注册，或见 [docs/故障排查.md](故障排查.md)。

## 六、标签页④「执行记录」

**当前账号**的每一次运行（手动触发或定时触发）都会留下一条记录（存于 `userdata/accounts/<别名>/runs/`），**每账号只保留最近 3 条**，更早的连同截图目录会被自动彻底删除。切号即换数据源；明细/截图按运行记录自身归属账号反查，切号后点开旧记录也能正确显示。

- **列表**：时间、状态、目标。
  - 状态徽章：`运行中` / `成功` / `需验证` / `失败`。
- **点击任意一行**打开「执行详情」弹窗：
  - **元信息**：开始/结束时间、状态、账号、目标、错误（若有）。
  - **需验证提示**：若状态为「需验证」，会给出明确指引（去「一键触发」点「打开浏览器」手动处理，再重新触发）。
  - **完整日志**：本次运行的全部日志文本。
  - **证据截图**：本次运行在关键节点保存的截图（打开会话、发送后、失败审计），点击可放大查看（灯箱）。
    - 截图文件名形如 `001_175445_audit_no_match.png` 或 `005_175500_after_send.png`，前缀序号即执行顺序。

## 七、并发与清理规则

- **同一时刻只能有一个任务在跑**（进程内锁 + 跨进程 `.running` 守卫双层，跨面板/runner/命令行进程都互斥）。触发运行时其他触发类按钮会禁用（含另一账号在跑时）；若状态卡死用「重置运行」兜底；若上次进程崩溃留下陈旧守卫，下次触发会按 pid 存活探测自动清理（自愈）。
- **「打开浏览器」窗口**与「选会话同步」「触发运行」「迁移」互斥，会相互等待。
- 执行记录**每账号只保留最近 3 条**；删除是连同元数据、日志、截图目录一并彻底删除，不残留，且只清当前账号目录（不误删他号记录）。
- 面板每次启动也会逐账号裁剪一次旧记录。

## 八、接口一览（供进阶/二次开发）

面板为纯标准库 `http.server`，无外部依赖。**MAI-001 后除 `/api/accounts`（GET 全局）、runs 明细/截图（按 meta.account 反查）与 BAT-001 批量三端点（`/api/trigger-all` `/api/batch-state` `/api/batch-cancel`，全局无账号语义）外，各端点均带 `account` 参数**（GET 走 query，POST 走 body；动作路径缺 account 直接 400）：

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/accounts` | 账号列表（含 has_task）、legacy 状态、上次账号（全局，不带 account） |
| GET | `/api/state` | 当前账号运行状态、进度、配置摘要（含 running_account） |
| GET | `/api/runs` | 当前账号执行记录列表（自动裁剪到最近 3 条） |
| GET | `/api/runs/<id>` | 单次运行详情（按 meta.account 反查，无需 account 参数） |
| GET | `/api/runs/<id>/screenshots` | 该次运行的证据截图列表（按 meta.account 反查） |
| GET | `/api/screenshots/<id>/<file>` | 单张截图文件（含路径穿越防护，按 meta.account 反查） |
| GET | `/api/tasks` | 当前账号系统定时任务状态、时间/内容 |
| GET | `/api/conversations` | 当前账号会话同步状态、已扫描列表、已保存目标 |
| POST | `/api/accounts` `{alias}` | 添加账号（400 非法别名 / 409 已存在） |
| POST | `/api/migrate` `{alias}` | 迁移旧版单账号数据（进程内锁 + 跨进程守卫双查） |
| POST | `/api/tasks/adopt-legacy` `{alias}` | 用该账号时间/内容注册新任务并删除旧 `DouyinAutoFire`（无 schedule.time 时 400 提示先设时间） |
| POST | `/api/select` `{alias}` | 记忆当前账号 + 后端内存会话镜像切换 |
| POST | `/api/trigger` | 触发一次运行（强制可见浏览器） |
| POST | `/api/save-message` | 仅保存当前账号发送内容 |
| POST | `/api/setup-login` | 打开可见浏览器供当前账号登录/验证 |
| POST | `/api/login-reset` | 强制重置登录窗口状态（全局） |
| POST | `/api/run-reset` | 强制重置运行状态（全局） |
| POST | `/api/sync-conversations` | 启动当前账号会话扫描 |
| POST | `/api/save-targets` | 保存当前账号所选会话 |
| POST | `/api/trigger-all` | **一键出发**：拉起独立执行器 `batch_runner.py --batch-all`，全部账号串行错峰跑一轮（批量激活/面板有运行/无账号时 400/409/423） |
| GET | `/api/batch-state` | 批量执行器状态（active/crashed/逐号 items，全局无 account） |
| POST | `/api/batch-cancel` | 请求取消批量（最小写集只置 `cancel_requested`；无进行中批量时 400） |
| POST | `/api/tasks` | 保存当前账号时间/内容并注册定时任务 |
| POST | `/api/tasks/enable` `/disable` `/delete` | 启用/禁用/删除当前账号系统任务 |
| POST | `/api/shutdown` | 退出面板服务 |
