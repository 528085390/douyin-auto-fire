每天定时（或手动一键）自动打开浏览器，给指定的**私聊 / 群聊**各发一条消息，维持抖音「火花」连续天数。支持同时续多个目标（私聊火花 + 群聊火花混合），登录态持久化，首次扫码后长期免登录。

基于 **Playwright**（真实 Chromium / 本机 Chrome）控制浏览器，直接打开抖音 IM 独立页 `https://www.douyin.com/chat` 操作（抖音改版后「消息」浮层入口已废弃），不尝试破解任何安全验证。

## 一、核心特性

- **多账号隔离**（MAI-001）：多个抖音号各自一个目录 `userdata/accounts/<别名>/`，登录态、目标会话、发送内容、执行记录完全独立；面板顶部账号栏切换，跨进程 `.running` 守卫保证同一时刻绝不并发。（定时任务从「每账号一条 schtasks」演进为「任务条目库 + 常驻守护」后仍按账号归属、到点自动串行错峰执行，见下。）
- **多目标**：每个账号可配多个会话（私聊 `private` / 群聊 `group`），逐个发送。
- **两种运行方式**：
  - 管理面板（推荐）：图形界面，选账号 / 选会话 / 前台触发 / 定时任务 / 执行记录一目了然。
  - 命令行：`main.py` 交互菜单（先选账号）或 `--run-once --account <别名>` 直接发送。
- **定时无人值守**：常驻守护进程（`scheduler_daemon.py`）驱动——任务条目库（`userdata/scheduler_jobs.json`）存账号/时刻/目标/文案，守护 ~20 秒主循环到点自动切换对应账号串行执行（同号可多条、同刻自动错峰 ≥15 分钟、错过当天时刻恢复后补跑一次），心跳写 `userdata/scheduler_heartbeat.json`，开机经注册表 Run 自启（值 `DouyinAutoFireScheduler`），**不依赖 Windows 任务计划程序**。旧版 schtasks 任务由面板「定时任务」页一键迁移/清理收尾。
  > 命令行路径 `python main.py HH:MM --account <别名>` 仍走 Windows 任务计划程序注册 `DouyinAutoFire-<别名>`（兼容旧用法/迁移收尾），面板推荐走守护定时。
- **反自动化防护**：反指纹注入 + 仿人操作（曲线移动、按字节奏打字、目标间随机等待）+ 只往当前会话聊天框填字、显式排除 IM 搜索框。
- **安全验证优雅停手**：一旦检测到验证码 / 滑块 / 拼图，**立即终止本次发送**，标记为「需验证」，由你在浏览器里手动处理，绝不停留、不破解。
- **审计与证据**：每次运行产生独立目录，关键节点（打开会话、发送后、失败审计）自动截图 + 结构化 JSON 证据，可在「执行记录」里直接查看，并可区分「真的找不到会话」还是「误判」。

## 二、目录结构

```
douyin-auto-fire/
├── main.py                  # 入口：交互菜单、--run-once / --setup-login / --test、非交互 HH:MM
├── verify.py                # 自检脚本：改完代码跑一次，验证定时链路是否完好
├── runner.py                # schtasks 定时任务入口（pythonw 调用，自动 chdir + 兜底写日志；迁移自旧机制）
├── jobs.py                  # 定时任务条目存取（SCH-001：userdata/scheduler_jobs.json，面板 CRUD / 迁移唯一写方）
├── scheduler_daemon.py      # 常驻调度守护（SCH-001：~20s 主循环、到点/补跑入队、串行执行、错峰 15 分钟、心跳、注册表 Run 自启）
├── batch_runner.py          # 一键出发批量执行器（BAT-001：全部账号串行错峰跑一轮，独立进程，面板可关不丢队列）
├── pyenv.py                 # Python 解释器探测与校验（定时任务/启动脚本共用）
├── douyin.py                # Playwright 自动化核心（浏览器、会话切换、发送、风控、审计）
├── panel.py                 # 本地管理面板（HTTP 服务，纯标准库）
├── panel.html               # 管理面板前端页面
├── config.yaml              # 公开配置（浏览器、日志、面板端口）；时间/目标/消息在 userdata/accounts/<别名>/user_data.yaml（私有，整体 gitignore）
├── userdata/                # 用户私有数据（会话名/发送内容/登录态/审计/面板日志）—— 整体 .gitignore，永不进 git
│   ├── accounts/<别名>/      #   每个抖音账号一个目录（MAI-001）
│   │   ├── user_data.yaml    #     私有配置（targets/message/schedule）
│   │   ├── browser_data/     #     该账号登录态（自动生成，请勿删）
│   │   ├── conversations_cache.json # 该账号会话列表缓存
│   │   └── runs/             #     该账号审计记录（自动生成）
│   ├── .running              #   跨进程运行守卫（独占文件，运行结束自动删除）
│   ├── scheduler_jobs.json   #   定时任务条目库（守护读取）
│   ├── scheduler_state.json / scheduler_heartbeat.json # 守护状态/心跳
│   ├── panel_state.json      #   面板记忆的上次账号 {last_account}
│   ├── run.log / panel.log   #   基础设施日志（全局，不分账号）
│   └── user_data.yaml / browser_data / runs / conversations_cache.json  # 旧版单账号数据（迁移后清空）
├── user_data.yaml.example   # 私有数据结构参考模板（进 git）；实际数据由面板添加账号/迁移生成
├── requirements.txt         # Python 依赖
├── LICENSE                  # MIT 许可证
├── CHANGELOG.md             # 版本变更记录
├── .gitattributes           # 行尾规范（文本入库 LF；Windows 批处理检出 CRLF）
├── 启动项目.bat             # 双击启动管理面板（后台无窗口，自动清理旧实例并打开浏览器）
├── 关闭项目.bat             # 双击停止后台面板服务
├── .venv/                   # 项目虚拟环境（uv venv .venv 创建）
├── design-system/           # 前端样式系统（设计参考资源，非运行依赖）
```

## 三、快速开始

> 详细步骤见 **[docs/管理面板使用指南.md](docs/管理面板使用指南.md)** 与 **[docs/命令行与定时任务.md](docs/命令行与定时任务.md)**。

0. **获取代码**：`git clone` 本仓库（或 GitHub 页面「Code → Download ZIP」）后进入项目目录。
1. **准备环境**：Windows 10/11 + Python 3.10+ + **本机已安装 Google Chrome**（`config.yaml` 的
   `browser.channel: "chrome"` 默认启用，用于规避 Playwright 自带 Chromium 被抖音风控）。
   创建虚拟环境并装浏览器内核：
   ```bash
   uv venv .venv
   uv pip install --python .venv/Scripts/python.exe -r requirements.txt
   .venv/Scripts/python.exe -m playwright install chromium
   ```
   > 项目所有脚本（定时任务、bat/vbs）都会自动探测 `.venv`，不要把它建在别处。
2. **启动管理面板**（推荐双击 `启动项目.bat`，或命令行）：
   ```bash
   .venv/Scripts/python.exe panel.py   # 默认监听 http://127.0.0.1:8765
   ```
3. **添加账号并登录**：面板顶部账号栏点「＋ 添加账号」，输入别名（1~24 个英文/数字/下划线，如 `main`），随后自动弹出浏览器扫码登录该号（登录态持久化在 `userdata/accounts/<别名>/browser_data/`）。
   - 曾用旧版单账号：面板顶部会出现**迁移引导条**，输入别名点「开始迁移」把旧数据整体迁入账号目录；若检测到旧定时任务，再点「同步注册新任务并删除旧任务」收尾。
4. **选会话**：在「一键触发」页点「一键同步」扫描当前账号的私信 / 群聊，勾选要续火花的会话并点「保存所选」（写入该账号的 `userdata/accounts/<别名>/user_data.yaml` 的 `targets`）。填好要发送的内容后，点「前台触发」或「保存内容」即可发送 / 仅保存。
5. **定时发送**：切到「定时任务」页，点「新建定时任务」填发送时间 + 内容（目标省略则用该号已保存的目标），保存即入任务库；常驻守护（`scheduler_daemon.py`，开机自启）到点自动运行。同号可设多条、同刻自动错峰；错过当天时刻恢复后补跑一次。旧版 Windows 定时任务数据可用页内「迁移/清理」入口一键接入。
6. **添加第二个账号 / 切换账号**：再点「＋ 添加账号」输入别名（如 `backup`）扫码登录第二个号；账号栏下拉即可切换当前账号，三块数据（会话 / 发送内容 / 执行记录 / 定时任务）随账号联动。
   > ⚠️ 两个号的定时时间请**错峰 ≥15 分钟**（如 `21:00` / `21:30`）：跨进程 `.running` 守卫保证同一时刻绝不并发（风控纪律），错峰可避免撞车时后一个号被跳过。详见 [docs/管理面板使用指南.md](docs/管理面板使用指南.md)「账号」一节。

> ⚠️ **不要把 `browser.headless` 改成 `true`**：抖音对无头浏览器 100% 弹拼图验证，定时任务会一条都发不出去。
> 保持默认的 `headless: false`（真实有头浏览器），窗口正常显示在屏幕内，定时任务运行时你会看到一个可见的浏览器窗口。
> ⚠️ **多账号期间 `browser.real_chrome_profile` 必须保持 `false`**：为 `true` 时登录态指向真实 Chrome 目录、绕过账号隔离，两个账号会共用同一份登录态（串号）。

## 五、改完代码后自检

项目没有单元测试，改动后请跑一次自检（不发消息、不改已注册的任务，随时可安全运行）：

```bash
.venv/Scripts/python.exe verify.py
```

它会验证：解释器探测是否有效、旧 schtasks 入口 runner 的兜底日志、面板健康自检能否识别故障、
浏览器是否会挪到屏幕外、配置是否处于会被抖音风控拦截的状态、会话查找与发送强校验链、
BAT-001 一键出发与 SCH-001 守护定时机制的自检断言、以及 bat/vbs 里有无残留死路径。
全部通过时退出码为 0。

## 六、重要提示

- **不要用 `file://` 直接双击打开 `panel.html`**，否则浏览器走 `file://` 协议连不上本地服务，「定时任务」「执行记录」会一直「加载失败」。务必通过 `python panel.py` 或双击 `启动项目.bat` 打开 `http://127.0.0.1:8765`。
- **同一时刻只能有一个任务在跑**（浏览器数据目录锁冲突），面板会拦截并发触发；正在运行时其他按钮会自动置灰。
- **维护火花需双方**在 24 小时内都发消息，本程序只负责你这一侧。
- **抖音对自动化有检测**，请勿高频触发、群发、或用于违规用途。本项目仅供个人维系「火花」使用。
